# FramedLift

Рабочий фрейм (camouflage-блок) на базе FramedBlocks + Create + Sable, для Minecraft 1.21.1 / NeoForge 21.1.265.

## Сборка
Сборка идёт через GitHub Actions: пуш в main -> runData -> автокоммит сгенерированных данных -> build -> артефакт с jar.

## Важно: gradle wrapper
Gradle wrapper (gradlew, gradlew.bat, gradle/wrapper/gradle-wrapper.jar и .properties) в архив не входит —
возьмите их из вашего локального MDK-проекта и положите в корень репозитория.

## Запуск в игре
Нужны рядом: FramedBlocks 10.4.x (или совместимая), Create 6.x, Sable 2.x.
